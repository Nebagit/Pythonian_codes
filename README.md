# Python Crash Course — Challenges & Problem Solving

A curated collection of Python training files, challenge problems, and hands-on exercises designed to build strong programming fundamentals.  
This repository includes beginner-to-intermediate practice tasks covering variables, loops, functions, data structures, OOP, file handling, algorithms, and more.

Whether you are revising Python, preparing for interviews, or practicing clean coding principles, this repo provides clear examples and practical exercises.


## 🚀 Features

- Beginner–friendly Python practice exercises  
- Challenges covering real-world scenarios  
- Organized examples for easy learning  
- Covers major Python fundamentals:
  - Variables & Data Types  
  - Conditional Statements  
  - Loops  
  - Functions  
  - Lists, Tuples, Sets, Dictionaries  
  - File Handling  
  - Error Handling  
  - Object-Oriented Programming  
  - Basic Algorithms  
- Clean and simple code structure  
- Great for revision, teaching, or self-study

## 🛠️ Tech Stack

- **Language:** Python 3  
- **Tools:** Any IDE/Text Editor (VS Code, PyCharm, Jupyter Notebook, etc.)

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Nebagit/Pythonian_codes.git
````

2. Navigate to the project folder:

```bash
cd Pythonian_codes
```

3. Run any Python file:

```bash
python filename.py
```
